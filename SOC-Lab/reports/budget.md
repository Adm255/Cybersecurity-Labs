# Adam's Company Limited
# Cybersecurity SOC Budget

## 1. Purpose

This budget provides an estimated cost allocation for establishing the proposed Cybersecurity Operations Center (SOC) at Adam's Company Limited.

The total available budget is:

**10,000,000 FRW**

The budget prioritizes essential security infrastructure, backup capability, personnel development, implementation, and future flexibility.

## 2. Budget Approach

Because the organization has a limited cybersecurity budget, the proposed SOC will:

- Prioritize the highest cybersecurity risks.
- Reuse existing infrastructure where appropriate.
- Use open-source security technologies where practical.
- Focus spending on essential hardware and infrastructure.
- Provide resources for implementation and training.
- Maintain a contingency reserve for unexpected requirements.

The software stack will prioritize technologies such as Wazuh, Suricata, Wireshark, Greenbone/OpenVAS, IRIS, and Linux to reduce software licensing costs.

## 3. Estimated Budget Allocation

| Category | Estimated Cost (FRW) | Justification |
|---|---:|---|

| Firewall / network security equipment | 1,000,000 | Provides network perimeter protection and supports segmentation |
| Backup and storage infrastructure | 1,000,000 | Protects critical data, logs, evidence, and supports recovery |
| Network equipment / monitoring infrastructure | 800,000 | Supports secure connectivity and network monitoring |

## 4. Budget Justification

### 4.1 SOC Server / Computing Infrastructure — 3,000,000 FRW

The SOC requires suitable computing infrastructure to host centralized security monitoring and related services.

The infrastructure may support:

- Wazuh
- Security log collection
- Security monitoring services
- Incident management services
- Vulnerability management services where appropriate

The organization should select hardware based on actual workload requirements and available infrastructure.

### 4.2 Firewall / Network Security Equipment — 1,000,000 FRW

The firewall provides the primary security boundary between the company network and external networks.

The allocation supports:

- Firewall hardware or suitable security appliance
- Network protection
- Traffic filtering
- Network segmentation
- Security logging

### 4.3 Backup and Storage Infrastructure — 1,000,000 FRW

Backup and storage are essential for protecting business information and supporting recovery from ransomware, accidental deletion, hardware failure, or other incidents.

The allocation supports:

- Backup storage
- Security log storage
- Incident evidence storage
- Recovery requirements

Backup infrastructure should be protected from unauthorized access and, where possible, separated from production systems.

### 4.4 Network Equipment / Monitoring Infrastructure — 800,000 FRW

Additional network equipment may be required to support secure connectivity and security monitoring.

This allocation may support:

- Network switches
- Monitoring interfaces
- Network connectivity
- Security monitoring infrastructure

Existing equipment should be reused where it meets security and performance requirements.

### 4.5 SOC Analyst Workstation — 500,000 FRW

A dedicated workstation provides the SOC analyst with a suitable environment for:

- Security monitoring
- Alert investigation
- Network analysis
- Incident documentation
- Security reporting

### 4.6 UPS / Power Protection — 500,000 FRW

Power protection is important for SOC infrastructure because unexpected power interruptions can affect monitoring systems, storage, and security services.

The allocation supports suitable UPS and power protection equipment.

### 4.7 Cybersecurity Training and Awareness — 800,000 FRW

Security depends on both technology and people.

The training allocation supports:

- SOC analyst training
- Security awareness for employees
- Incident response training
- Security tool training
- Phishing awareness
- Cybersecurity best practices

### 4.8 Implementation and Configuration — 900,000 FRW

The implementation allocation supports the future deployment of the proposed SOC.

Activities may include:

- Infrastructure preparation
- Security tool deployment
- Configuration
- Integration
- Testing
- Documentation
- Initial operational setup

This allocation represents implementation effort and related setup costs, not current deployment.

### 4.9 Contingency / Future Security Needs — 1,500,000 FRW

A contingency reserve is included because actual procurement and implementation costs may vary.

The reserve may be used for:

- Unexpected hardware requirements
- Additional storage
- Replacement equipment
- Security improvements
- Priority vulnerabilities
- Future SOC requirements

The contingency should only be used for approved security or project requirements.

## 5. Open-Source Technology Strategy

The proposed SOC will prioritize open-source technologies where they meet the organization's security requirements.

Examples include:

- Wazuh
- Suricata
- Wireshark
- Greenbone/OpenVAS
- IRIS
- Linux

Using these technologies can significantly reduce commercial software licensing costs.

The budget can therefore focus on infrastructure, implementation, training, and operational requirements.

## 6. Resource Optimization

To remain within the 10,000,000 FRW budget, the organization should:

- Reuse suitable existing servers and network equipment.
- Reuse existing IT personnel where appropriate.
- Prioritize critical systems.
- Deploy monitoring first on high-value assets.
- Use open-source technologies where practical.
- Expand the SOC gradually as resources become available.

## 7. Budget Assumptions

This budget is a **planning estimate** for the proposed SOC.

The following assumptions apply:

- Existing company infrastructure may be reused where suitable.
- Open-source security software will be used where appropriate.
- Final hardware specifications will depend on actual system requirements.
- Supplier quotations should be obtained before procurement.
- Prices may change due to market conditions, availability, taxes, shipping, and supplier differences.
- Implementation costs may vary depending on whether deployment is performed internally or with external support.

Therefore, the figures should not be treated as final vendor quotations.

## 8. Budget Priority

If the organization must reduce spending further, the recommended priority is:

1. SOC computing infrastructure
2. Firewall and network protection
3. Backup and storage
4. Security monitoring
5. Implementation and configuration
6. Training and awareness
7. Power protection
8. Additional improvements and contingency

Critical security controls should be protected from budget reductions where possible.

## 9. Budget-to-Risk Alignment

The budget directly supports the risks identified during the risk assessment.

| Identified Risk | Budget Support |
|---|---|
| Ransomware | Backup infrastructure, endpoint monitoring, training |
| Network intrusion | Firewall and network monitoring infrastructure |
| Account compromise | MFA and security awareness |
| Vulnerable systems | Vulnerability management infrastructure |
| Security log loss | SOC computing and storage infrastructure |
| Malware | Wazuh, endpoint monitoring, training |
| Data loss | Backup and storage infrastructure |
| Unauthorized access | Firewall, MFA, access controls |

## 10. Conclusion

The proposed 10,000,000 FRW budget provides a practical foundation for establishing a small, centralized SOC at Adam's Company Limited.

The allocation prioritizes critical security infrastructure while reducing software licensing costs through the use of open-source technologies.

The organization should validate all estimated costs through supplier quotations before procurement and adjust the allocation according to actual requirements while maintaining the total approved budget of 10,000,000 FRW.
