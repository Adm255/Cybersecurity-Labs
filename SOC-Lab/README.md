# 🛡️ SOC Lab — Cybersecurity Monitoring & Detection

## Overview
This lab demonstrates core SOC skills using:
- **Elastic Stack** (SIEM)
- **Kali Linux** (Attacker & Analyst)
- **Metasploitable 2** (Target)

## Setup
1. Run `setup/elastic_stack_install.sh`
2. Access Kibana at `http://localhost:5601`
3. Start generating logs with `nmap` and `hydra`

## Exercises
- [Exercise 1: Brute Force Detection](exercises/exercise-1_brute_force.md)
- [Exercise 2: Port Scan Detection](exercises/exercise-2_port_scan.md)
- [Exercise 3: Web Attack Detection](exercises/exercise-3_web_attack.md)

- Nmap, Hydra, Metasploit
